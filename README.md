# Salar Ahsan — AI Developer | Links Page

A single-file, 3D animated links/portfolio page for **Salar Ahsan** — Google Certified Data Analyst & AI Automation Specialist based in Mandi Bahaudin, Pakistan.

🔗 **Live:** [salar-ahsan-links.vercel.app](https://salar-ahsan-links.vercel.app)

## About

This page brings together all of Salar's professional links — portfolio, GitHub, socials, and freelance profiles — in one clean, interactive hub. Built as a lightweight static site with no frameworks or build step.

## Features

- 🎨 Soft glassmorphic design with an animated floating 3D orb hero
- 🖱️ Mouse-follow glow / spotlight effect
- 🃏 Tilt-on-hover glass cards for each link
- 📱 Fully responsive, single HTML file (HTML + CSS + JS, no dependencies except Google Fonts)

## Tech

- Pure HTML5, CSS3 (backdrop-filter, 3D transforms, keyframe animations)
- Vanilla JavaScript (no libraries)
- Fonts: [Fraunces](https://fonts.google.com/specimen/Fraunces), [Inter](https://fonts.google.com/specimen/Inter), [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono)
